# ป้ายระบุและควบคุมการใช้จัมโบ้ (Jumbo QR Tracker)

เว็บแอปสำหรับติดตามจำนวนครั้งการใช้งานถุงจัมโบ้ (Jumbo bag) แต่ละใบด้วย QR Code
จำกัดการใช้งานไม่เกิน 20 ครั้งต่อใบ พร้อมบันทึกความสะอาด/ความสมบูรณ์ ผู้บันทึก
ผู้ตรวจสอบ และหมายเหตุ ทุกครั้งที่ใช้งาน ข้อมูลซิงค์แบบเรียลไทม์ (ไม่มีดีเลย์) ระหว่าง
ผู้ใช้งานทุกคนผ่าน Firebase Firestore

เป็นไฟล์เดียว (`index.html`) ไม่ต้องมีเซิร์ฟเวอร์ฝั่งหลังบ้าน — โฮสต์เป็นเว็บ static
ธรรมดาได้ทั้งบน GitHub Pages หรืออินทราเน็ตของบริษัท

## ฟีเจอร์

- เพิ่ม/ลบจัมโบ้ได้เอง เลือกชนิดข้าว (ข้าวไทย / ข้าวญี่ปุ่น) — เลขจัมโบ้นับแยกกันคนละชุดต่อชนิด
- สร้าง QR Code เฉพาะของแต่ละจัมโบ้ (1 จัมโบ้ : 1 QR Code) ดาวน์โหลดไปพิมพ์ติดป้ายจริงได้
- สแกน QR ด้วยกล้อง เพื่อเปิดฟอร์มบันทึกการใช้งานของจัมโบ้ใบนั้นทันที (มีเมนูเลือกเองสำรองไว้)
- บันทึกทุกครั้งที่ใช้งาน: วันที่ / ความสะอาด / ความสมบูรณ์ / ผู้บันทึก / ผู้ตรวจสอบ / หมายเหตุ
- แจ้งเตือนเมื่อใกล้ครบและครบกำหนด 20 ครั้ง (ล็อกไม่ให้บันทึกเพิ่ม)
- พิมพ์ใบปะหน้า Summary รูปแบบเดียวกับป้ายกระดาษเดิม
- ส่งออกข้อมูลทั้งหมดเป็นไฟล์ Excel (.xlsx)
- ข้อมูลอัปเดตแบบเรียลไทม์ทันทีที่มีการบันทึก ไม่ต้องรอรีเฟรชหรือรอ polling

## การนำขึ้นใช้งานจริง (2 ขั้นตอนหลัก)

### 1) ตั้งค่าฐานข้อมูล Firebase (ทำครั้งเดียว)

1. สร้างโปรเจกต์ฟรีที่ [console.firebase.google.com](https://console.firebase.google.com)
2. เมนู Build → **Firestore Database** → สร้างฐานข้อมูล เลือกโหมด **Production**
3. เมนู Build → **Authentication** → Sign-in method → เปิดใช้งาน **Anonymous**
4. ไอคอนเฟือง → Project settings → เลื่อนหา "Your apps" → กด `</>` เพื่อลงทะเบียนเว็บแอป
   → คัดลอกค่า `firebaseConfig`
5. เปิด `index.html` ด้วยโปรแกรมแก้ไขข้อความ ค้นหาตัวแปร `firebaseConfig` แล้ว
   แทนที่ด้วยค่าที่คัดลอกมา จากนั้นบันทึกไฟล์
6. ไปที่ Firestore → แท็บ **Rules** วางกฎนี้แล้ว Publish:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```

### 2) ขึ้นเว็บบน GitHub Pages

1. สร้างบัญชี GitHub (ถ้ายังไม่มี) ที่ [github.com](https://github.com)
2. สร้าง repository ใหม่ เช่น ตั้งชื่อ `jumbo-tracker` (Public หรือ Private ก็ได้
   — ถ้า Private ต้องใช้ GitHub Pro ถึงจะเปิด Pages ได้ ถ้าไม่แน่ใจให้ตั้งเป็น Public)
3. อัปโหลดไฟล์ `index.html` (ที่แก้ `firebaseConfig` แล้ว) และ `README.md` นี้ เข้า repo
   — กด **Add file → Upload files** บนหน้าเว็บ GitHub ได้เลย ไม่ต้องใช้คำสั่ง git ก็ได้
4. ไปที่ **Settings → Pages**
5. หัวข้อ Source เลือก **Deploy from a branch** → Branch เลือก `main` และโฟลเดอร์ `/ (root)`
   → กด **Save**
6. รอประมาณ 1–2 นาที จะได้ลิงก์เว็บรูปแบบ
   `https://<ชื่อบัญชี>.github.io/jumbo-tracker/`
7. เปิดลิงก์นี้จากมือถือ/คอมพิวเตอร์ของพนักงานได้เลย เนื่องจาก GitHub Pages เป็น
   **HTTPS อยู่แล้ว** กล้องสแกน QR จึงใช้งานได้ทันที

> หมายเหตุ: ทุกครั้งที่แก้ไขไฟล์ `index.html` แล้วอัปโหลดทับใน repo เว็บจะอัปเดตให้อัตโนมัติ
> ภายในไม่กี่นาที

## โครงสร้างไฟล์

```
jumbo-tracker/
├── index.html   ← ตัวเว็บแอปทั้งหมด (ต้องแก้ firebaseConfig ก่อนใช้งานจริง)
└── README.md    ← เอกสารนี้
```
